About 4MLSim

What it is

4MLSim (Machine Learning Simulation Lab) is a set of interactive simulations for teaching machine learning, written by Professor Periklis Gogas at the EMEF Lab, Department of Economics, Democritus University of Thrace. Each module lets students change the data and the settings, run the algorithm step by step, and read the ideas at three depths: intuition, formulas, and a deep dive.

4MLSim is the teaching companion of 4Cast Lab, which trains and evaluates models on real data.

Install and offline use

        
    
          
  • Click Install 4MLSim in the header (Chrome or Edge), or use the browser menu: Edge Apps > Install this site as an app, Chrome Cast, save and share > Install page as app.
    • 
          
  • After the first visit every module works without internet.
    • 
          
  • A single-file version for computers with no internet at all: 4MLSim-offline.html.
    • 
        

      

      

        
Privacy

        
Everything runs in your browser. Data you draw or upload never leaves your computer. Your settings are remembered only in this browser. The only network request is a short check on GitHub for a newer version.
