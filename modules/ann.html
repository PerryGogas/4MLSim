What this module shows

A neural network is built from simple units, the neurons. Each one takes a weighted sum of its inputs, adds a bias, and passes the result through an activation function. Neurons are arranged in layers: inputs, one or more hidden layers, and the output (here the probability of class 1).

Training repeats two passes: the forward pass computes the prediction; the backward pass (backpropagation) computes how the loss changes with every weight, and gradient descent moves every weight a little.

How to use it

  2. Press Reset, then Play: watch the boundary bend and the loss fall.

The neuron

A neuron receives inputs x1, x2, ..., multiplies each by a weight, adds them up with a bias, and applies an activation function: a = f(w1x1 + w2x2 + ... + b). With the sigmoid as f and no hidden layer, the network is exactly a logistic regression.

  • ReLU: max(0, z). Simple and fast; the default in deep networks.
  • tanh: an S-curve from −1 to 1.
  • Sigmoid: an S-curve from 0 to 1; used for the output probability.

Without a nonlinear activation, any number of layers collapses into one weighted sum: a straight boundary. The activations let the network bend its boundary; more hidden neurons and layers allow more bends.

Training: forward and backward

  1. Forward pass: for every observation, compute the hidden layers and the output probability.
  2. Loss: the average log loss (as in logistic regression): small when the probabilities are right.
  3. Backward pass (backpropagation): apply the chain rule from the output back to the first layer to get the gradient of the loss for every weight.
  4. Update: move every weight against its gradient: w ← w − (learning rate) × gradient. One pass over the training set is an epoch.

Here the whole training set is used in every step (batch gradient descent) with momentum 0.9 (each step keeps 90% of the previous one), on standardized inputs. Real networks use small random batches (stochastic gradient descent) and optimizers such as Adam.

Things that go wrong

  • Learning rate too large: the loss jumps around or explodes. Too small: training takes forever. (See the Gradient Descent module.)
  • Overfitting: many neurons and long training fit the noise of the training set; watch the test loss. Remedies: fewer neurons, early stopping, regularization, dropout.
  • Vanishing gradients: the sigmoid's slope is at most 0.25, so gradients shrink layer by layer going backwards; the first layers learn slowly. ReLU avoids this.

Deep dive

Universal approximation. One hidden layer with enough neurons can approximate any continuous function on a bounded region; deeper networks often need far fewer neurons for the same accuracy.

Initialization. Weights start at small random values scaled by the number of inputs (He initialization for ReLU, Glorot/Xavier for tanh and sigmoid); all-equal weights would make every neuron in a layer learn the same thing. Different seeds give different networks.

Non-convex loss. The loss has many local minima and flat regions; gradient descent finds one of them, which is usually good enough.

References: Rumelhart, Hinton and Williams (1986), "Learning representations by back-propagating errors", Nature; Hornik, Stinchcombe and White (1989), Neural Networks; Goodfellow, Bengio and Courville (2016), Deep Learning, ch. 6.

From the simulation to real data

  • Neural networks shine with large data sets and unstructured inputs (text, images, many series). On small tabular economic data, tree ensembles and regularized regressions are often as good and easier to explain.
  • Standardize the inputs, start small, watch the validation loss for early stopping, and tune the learning rate. In Python: sklearn.neural_network.MLPClassifier, or Keras / PyTorch for larger models.
