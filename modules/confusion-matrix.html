What this module shows

A model that predicts bank failures gives each bank a probability of failure. With a threshold T each bank is called failed or healthy. Comparing these predictions with what actually happened gives the confusion matrix: true positives, false negatives, false positives and true negatives.

From these four numbers come accuracy, sensitivity, specificity, precision and F1. Which one matters depends on the target.

How to use it

  1. Move the threshold T and watch banks move between the four cells.
  2. Make failures rare with the "share of failed banks" slider: is accuracy that important?
  3. Compare the logit with the two naive models ("all healthy", "all failed").

The confusion matrix

Extremely important in evaluating classification models. For every observation, the model predicts 1 (failed bank) or 0 (healthy), and we know the actual class. If the model predicts 1, it is either right (true positive, TP) or wrong (false positive, FP: a false alarm, a type I error). If it predicts 0, it is either right (true negative, TN) or wrong (false negative, FN: a missed case, a type II error). Counting them gives a 2 × 2 table, in numbers or in percentages of each actual class.

The metrics

  • Accuracy = (TP + TN) / all: how good is the model overall? Misclassification rate = (FP + FN) / all: how bad?
  • Sensitivity (recall) = TP / (TP + FN): what share of the failed banks is found?
  • Specificity = TN / (TN + FP): what share of the healthy banks is recognised? False alarms = 1 − specificity = FP / (TN + FP).
  • Precision = TP / (TP + FP): of the banks we called failed, how many really failed?
  • F1 = 2 × precision × sensitivity / (precision + sensitivity): one number that balances the two. F0.5 favours precision, F2 sensitivity.
With P actual 1s and N actual 0s
\text{Accuracy} = \frac{TP + TN}{P + N}, \quad \text{Sensitivity} = \frac{TP}{P}, \quad \text{Specificity} = \frac{TN}{N}, \quad \text{Precision} = \frac{TP}{TP + FP}
F_\beta = (1 + \beta^2)\,\frac{\text{Precision} \times \text{Sensitivity}}{\beta^2\,\text{Precision} + \text{Sensitivity}} \qquad (F_1:\ \beta = 1)

Is accuracy that important? Not always

With 99 healthy banks and 1 failed bank, a model that calls every bank healthy has 99% accuracy, 100% specificity, and 0% sensitivity: it finds no failed bank. The naive model "all failed" does the opposite: it detects every failed bank (100% sensitivity) but gives 100% false alarms. When one class is rare, look at sensitivity, specificity and precision, not only at accuracy.

Changing the threshold

Models give a probability; by default an observation is classified as 1 when it is at least 0.5. Lowering T finds more 1s: banks move from "predicted healthy" to "predicted failed", in the same row of the matrix. A failed bank moves from FN to TP: sensitivity rises and precision usually rises. A healthy bank moves from TN to FP: specificity falls, false alarms rise and precision falls. There is a trade-off; which side we prefer depends on the cost of each error (see the ROC, PR & Calibration module).

Training set and test set

The matrix can be computed on the training set and on the test set. The test set (new banks) is the honest one; a much better training matrix means overfitting.

Deep dive

Prevalence and precision. Sensitivity and specificity do not depend on how common failures are; precision does. With prevalence π, precision = sens·π / (sens·π + (1 − spec)(1 − π)). With π = 1% even 95% sensitivity and 95% specificity give a precision of only 16%: most alarms are false.

More than two classes. The matrix becomes K × K; sensitivity and precision are computed per class (one class against the rest) and can be averaged (macro or weighted averages).

Balanced accuracy = (sensitivity + specificity) / 2 is not fooled by rare classes: the "all healthy" model gets 50%.

References: Fawcett (2006), "An introduction to ROC analysis", Pattern Recognition Letters 27(8); Sokolova and Lapalme (2009), "A systematic analysis of performance measures for classification tasks", Information Processing & Management 45(4).

From the simulation to real data

  • Bank failures, fraud, defaults and crises are rare: report sensitivity, specificity and precision next to accuracy, and say how rare the 1s are.
  • Choose the metric from the decision: a supervisor who must not miss a failing bank wants high sensitivity; a fraud team with few investigators wants high precision.
  • Always show the confusion matrix of the test set, not only of the training set.
  • Example from the lecture: a linear SVM on US bank failures (115 insolvent, 1,164 solvent banks) reached 99% accuracy while the naive "all insolvent" model detected every failure with 100% false alarms.
