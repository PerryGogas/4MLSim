What this module shows

Try enough trading rules (or forecasting models) on the same data, and one of them will look excellent by pure luck. Picking the best and reporting its t-statistic as if it were the only one tried is data snooping.

Here you test up to 300 moving-average trading rules on two years of daily stock returns, then see how the "best" rule does in the following year, and what the proper tests say: Bonferroni, White's Reality Check, Hansen's SPA and the Model Confidence Set.

How to use it

  1. Start with a market where no rule has real skill. Raise the number of rules and watch the best in-sample t-statistic grow.
  2. Compare the naive p-value with the Reality Check and SPA p-values.
  3. Look at the next year: does the winner keep winning? Then switch on a small real effect.

The problem

A single test at the 5% level wrongly finds an effect 5% of the time. Test 100 useless rules and about 5 will look "significant"; the best of them will look very good. The more models are tried on the same data, the more impressive the best one looks, even when none has any real skill. In finance and economics, where there is one history of the markets and everyone searches it, this is a central problem.

Signs of snooping

  • The winner's in-sample t-statistic is high, but it falls back in new data (out-of-sample).
  • In-sample and out-of-sample performance of the rules are unrelated.
  • Nobody reports how many rules or models were tried.

Corrections

  • Bonferroni: multiply the p-value by the number of rules M. Simple, but far too strict when the rules are similar (correlated), as moving-average rules are.
  • White's Reality Check (2000): is the best rule better than the benchmark, taking into account that it is the best of M? It compares the best performance with the bootstrap distribution of the maximum over all rules, keeping their correlation.
  • Hansen's SPA test (2005): a more powerful version: it standardizes each rule's performance and is not misled by adding many poor rules.
  • Model Confidence Set (Hansen, Lunde and Nason 2011): instead of one winner, the set of rules that cannot be told apart from the best at a chosen level (here 10%). A large set means the data cannot pick a winner.
  • And always: a true out-of-sample period, untouched during the search.
The statistics
d_{k,t} = s_{k,t}\, r_t, \qquad \bar d_k = \frac{1}{T} \sum_t d_{k,t}, \qquad t_k = \frac{\bar d_k}{\hat\sigma_k / \sqrt{T}}
\text{Reality Check: } V = \max_k \sqrt{T}\, \bar d_k, \qquad V^*_b = \max_k \sqrt{T}\, \bigl(\bar d^*_{k,b} - \bar d_k\bigr), \qquad p = \frac{1}{B} \sum_b \mathbf{1}\{V^*_b \ge V\}
\text{SPA: } T^{SPA} = \max\Bigl(\max_k \frac{\sqrt{T}\, \bar d_k}{\hat\omega_k},\, 0\Bigr), \quad \text{bootstrap recentred at } \bar d_k \mathbf{1}\Bigl\{\frac{\sqrt T \bar d_k}{\hat\omega_k} \ge -\sqrt{2 \log\log T}\Bigr\}

sk,t = +1 (long) or −1 (short), decided with prices up to the day before; rt the market return; the benchmark is 0. Bootstrap: stationary bootstrap of whole days, so the correlation between rules is kept. Reality Check and Model Confidence Set results were checked against the Python package arch.

Deep dive

Expected maximum. For M independent standard normal t-statistics the expected maximum grows like √(2 log M): about 1.5 for M = 5, 2.5 for 100, 2.9 for 300. Correlated rules grow more slowly, which the bootstrap captures and Bonferroni ignores.

Model Confidence Set. Starting from all rules, test whether all have equal expected performance (Tmax statistic, bootstrap); if rejected, remove the worst and repeat. The rules left when the test no longer rejects form the set; each rule's MCS p-value is the largest test p-value up to its removal.

Forecast comparisons. The same tools apply to forecasting models (losses instead of returns), and the Diebold-Mariano test compares two forecasts.
