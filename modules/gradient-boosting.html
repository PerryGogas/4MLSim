What this module shows

Gradient boosting builds a model from many small trees added one after another. It starts with a simple prediction (the average). Each new tree is fitted to the errors that are still left, and only a fraction of it, the learning rate, is added. Step by step the errors shrink.

A random forest grows its trees independently and lets them vote; boosting grows them in sequence, each one correcting the previous ones.

How to use it

  1. Press Reset, then Step: watch each tree learn the errors left by the previous rounds.
  2. Change the learning rate and the number of rounds.
  3. Follow the training and test results by round: when does boosting start to overfit?
  4. Switch to classification for the bank data.

Boosting: models in sequence

Ensemble methods train several models instead of one. Bagging (random forests) trains them independently on bootstrap samples and lets them vote. Boosting trains them one after another: each new model concentrates on what the previous ones got wrong.

Gradient boosting step by step

  1. Start with a simple prediction for everyone: the average of the target (regression) or the share of 1s (classification).
  2. Compute the errors left: actual minus forecast, for every training observation.
  3. Fit a small tree (depth 1 to 5) to these errors: it learns where the model is too low or too high.
  4. Add the tree to the model, multiplied by the learning rate (e.g. 0.1): a small, careful step.
  5. Repeat for the chosen number of rounds.
The update
F_0(x) = \bar y, \qquad r_i^{(m)} = y_i - F_{m-1}(x_i), \qquad F_m(x) = F_{m-1}(x) + \eta\, h_m(x)

hm is the tree fitted to the errors r(m); η is the learning rate. For squared error, the errors are the negative gradient of the loss: hence "gradient" boosting.

Classification

For classes the model builds a score, turned into a probability with the sigmoid (as in the logit). It starts from the share of failed banks; the error of each bank is (1 or 0) minus its current probability, and each tree pushes the scores in the right direction.

Classification (log-loss)
p_i = \frac{1}{1 + e^{-F_{m-1}(x_i)}}, \qquad r_i^{(m)} = y_i - p_i, \qquad \text{leaf value} = \frac{\sum r_i}{\sum p_i (1 - p_i)}

Learning rate and number of rounds

  • A small learning rate takes small steps: it needs more rounds, but usually generalizes better.
  • With many rounds the training error keeps falling, but later trees start to fit noise: the test error levels off and rises. Boosting can overfit, unlike adding trees to a random forest.
  • The number of rounds is chosen on validation data: stop when the validation error stops improving (early stopping).
  • Small trees (depth 1 to 3) are usually enough: each one only has to correct a little.
Deep dive

Functional gradient descent. Friedman (2001) views boosting as gradient descent in the space of functions: each tree approximates the negative gradient of the loss at the current forecasts, and the learning rate is the step size (see the Gradient Descent module).

Leaf values. For squared error the leaf value is the mean error in the leaf. For the log-loss, scikit-learn uses one Newton step per leaf, Σr / Σp(1 − p), as here (the tree structure itself is chosen by squared error on the errors).

Stochastic gradient boosting. Fitting each tree on a random half of the observations (subsampling) adds randomness that often improves the test error.

AdaBoost. The first boosting method (Freund and Schapire, 1997) gives misclassified observations a heavier weight in the next model; gradient boosting generalizes this idea to any loss.

References: Friedman (2001), "Greedy function approximation: a gradient boosting machine", Annals of Statistics 29(5); Friedman (2002), "Stochastic gradient boosting", Computational Statistics & Data Analysis 38(4); Hastie, Tibshirani and Friedman (2009), The Elements of Statistical Learning, ch. 10.

From the simulation to real data

  • Gradient boosting is among the most accurate methods for tabular data in economics and finance: demand and price forecasting, credit risk, nowcasting.
  • Tune three things together: the learning rate (small, 0.01 to 0.1), the number of rounds (by early stopping on validation data) and the tree depth (2 to 6).
  • Never choose the number of rounds on the test set.
