What is gradient descent?

Machine learning models are trained by choosing the parameters that make a loss (the total prediction error) as small as possible. For most models there is no formula for the best parameters, so they are found step by step with gradient descent:

  1. Start with a guess for the parameters.
  2. Compute the gradient: the direction in which the loss rises fastest.
  3. Take a small step the opposite way. The step size is the learning rate η.
  4. Repeat until the loss stops falling.

It is how logistic regression, neural networks and large language models are trained.

Four problems to try

  • One parameter: the loss as a curve with valleys and peaks; watch the tangent (the gradient) and each step.
  • Straight line: OLS has a formula, so you can check that gradient descent reaches the same answer.
  • Logistic regression: no formula exists; gradient descent is how the model is estimated.
  • Bumpy surface: several valleys. Where you start decides where you end up, as in neural networks.

Training means minimizing a loss

A model has parameters (for a straight line: intercept b₀ and slope b₁). A loss function measures how badly the model with those parameters fits the data: the mean squared error for a line, the log-loss for logistic regression. Training means finding the parameters with the smallest loss. If you plot the loss for every possible pair of parameters you get a landscape: the loss surface. Its contour lines are like height lines on a map.

Two common loss functions
\text{MSE}(b) = \frac1n\sum_i \bigl(y_i - b_0 - b_1 x_i\bigr)^2 \qquad \text{LogLoss}(b) = -\frac1n\sum_i \bigl[y_i\ln p_i + (1-y_i)\ln(1-p_i)\bigr],\; p_i = \frac{1}{1+e^{-(b_0+b_1x_i)}}

Walking downhill in fog

Gradient descent is like walking down a mountain in thick fog: you cannot see the valley, only feel the slope under your feet. The gradient is that slope: it points uphill, so you step the opposite way. Near the bottom the slope flattens, so the steps shrink by themselves and the walk settles.

Gradient and update rule
b \leftarrow b - \eta\,\nabla L(b), \qquad \nabla \text{MSE} = \frac{2}{n}\sum_i (\hat y_i - y_i)\begin{pmatrix}1\\ x_i\end{pmatrix}, \qquad \nabla\text{LogLoss} = \frac{1}{n}\sum_i (p_i - y_i)\begin{pmatrix}1\\ x_i\end{pmatrix}

The update rule and the learning rate

At every iteration gradient descent calculates

bnew = bold − η × gradient

With one parameter, the gradient is the first derivative of the loss function with respect to b: the slope of the tangent to the loss curve at the current b. With several parameters it is the vector of partial derivatives, one per parameter. The gradient tells you which way the loss rises and how steeply; the learning rate η decides how far you move the opposite way. For example, with η = 0.1 and a slope of 4 for b₁, you move b₁ down by 0.4. Try the One parameter problem to see the tangent and every step.

The learning rate η sets the step length. Too small and the walk takes forever. A little too large and you overshoot the bottom, land on the opposite slope and zig-zag. Much too large and each step lands higher than the last: the algorithm diverges.

When does gradient descent stop?

Gradient descent does not know where the minimum is, so it needs a stopping rule. The two common ones: stop when the gradient is almost zero (at a minimum the slope is flat), or stop when the loss stops falling (it changes by less than a small fraction). The threshold is called the tolerance. A maximum number of iterations is a safety limit in case the rule is never met. A loose tolerance saves time but can stop too early, for example on a flat stretch of the loss; a tight tolerance is more precise but slower. Note that the rule can also be met on a peak or a saddle, where the gradient is zero too.

Stopping rules
\lVert \nabla L(b_t) \rVert < \varepsilon \qquad\text{or}\qquad \frac{\lvert L(b_{t-1}) - L(b_t)\rvert}{\lvert L(b_{t-1})\rvert} < \varepsilon \qquad\text{or}\qquad t = t_{\max}

Why standardize X?

When X is in large units (square metres, euros) the loss surface becomes a long, narrow valley. A step that is safe across the steep walls is tiny along the valley floor, so progress stalls. Standardizing (subtract the mean, divide by the standard deviation) makes the surface round, and gradient descent crosses it in a few steps. The final model is the same; only the route changes.

Batch, mini-batch and stochastic

Batch gradient descent uses all observations for every step. Stochastic gradient descent (SGD) uses one random observation and mini-batch a small random group. Each step is far cheaper, which matters with millions of rows, but the direction is noisy, so the path wanders and keeps jittering near the bottom. Deep learning uses mini-batches.

Logistic regression: no formula, so we must descend

For a straight line, OLS gives the best parameters with a formula, and gradient descent is only an alternative. For logistic regression no such formula exists. Statistical software uses Newton's method (maximum likelihood); machine learning libraries use gradient descent. Both reach the same estimates, shown by the star.

Bumpy surfaces: local minima and saddle points

The loss of a line or a logistic regression is a single bowl (convex): any start leads to the same bottom. The loss of a neural network has many valleys. Gradient descent only goes downhill, so it stops in the valley where it started: a local minimum that may be worse than the global minimum. Between valleys there are saddle points, flat in one direction, where progress slows. That is why neural networks are trained several times from different random starts.

Deep dive: when and how fast gradient descent converges

For the least-squares loss the Hessian H = \tfrac{2}{n}X^\top X is constant, and after t batch steps the error along each eigenvector of H shrinks by (1-\eta\lambda_k)^t. Gradient descent converges if and only if

0 < \eta < \frac{2}{\lambda_{\max}(H)},

and its speed is set by the condition number \kappa = \lambda_{\max}/\lambda_{\min}: with the best fixed step the error falls by about (\kappa-1)/(\kappa+1) per iteration. Standardizing makes \tfrac1n X^\top X = I, so \kappa = 1 and the minimum is reached in one step with \eta = 1/2.

For the log-loss the Hessian H(b) = \tfrac1n\sum_i p_i(1-p_i)\,x_i x_i^\top changes with b and is bounded by \tfrac14\cdot\tfrac1n X^\top X, so a step size safe for least squares with the same X is also safe here. Newton's method uses b \leftarrow b - H(b)^{-1}\nabla L(b) and converges in a handful of iterations; it is what econometric software runs for maximum likelihood.

With a fixed η, stochastic gradient descent does not settle: it fluctuates around the minimum with a spread proportional to η. Convergence requires a decreasing step size with \sum_t \eta_t = \infty and \sum_t \eta_t^2 < \infty (Robbins and Monro, 1951).

Gradient descent in practice

  • Every neural network in 4Cast Lab and in modern AI is trained with a variant of gradient descent (mini-batches plus refinements such as momentum or Adam, which adapt the step size).
  • In practice, standardize the input variables, try a few learning rates on a log scale (0.001, 0.01, 0.1), and watch the loss curve: it should fall steadily and flatten.
  • A loss curve that jumps up and down or grows means the learning rate is too large.
