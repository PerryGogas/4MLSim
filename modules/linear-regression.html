What this module shows

A linear regression explains an outcome Y (for example a wage) with one or more variables X (schooling, experience...). The same estimated equation can be read with two different goals:

  • Econometrics (left panel): are the coefficients precisely estimated and statistically significant, and do the assumptions behind the standard errors hold? All observations are used.
  • Machine learning (right panel): how accurately does the model predict observations it has never seen? Part of the data is held back as a test set.

How to use it

  1. Choose a dataset and tick the X variables on the left.
  2. Read the coefficient table and the diagnostic tests.
  3. Compare the training error with the test error.
  4. Click any ? for an explanation, then try the Challenges tab.

The model

Linear regression assumes that the outcome is a weighted sum of the explanatory variables plus an error that collects everything else. Ordinary least squares (OLS) chooses the weights (coefficients) that make the sum of squared errors as small as possible.

Model and OLS estimator
y_i = \beta_0 + \beta_1 x_{i1} + \dots + \beta_p x_{ip} + \varepsilon_i, \qquad \hat\beta = (X^\top X)^{-1} X^\top y
\text{SSR} = \sum_i (y_i - \hat y_i)^2, \qquad R^2 = 1 - \frac{\text{SSR}}{\sum_i (y_i - \bar y)^2}

Two cultures, one equation

Econometrics and machine learning use the same OLS estimates but ask different questions (Breiman, 2001; Mullainathan and Spiess, 2017).

Reading the econometric output

  • Coefficient: the change in Y associated with a one-unit change in that X, holding the other X fixed.
  • Standard error: how much the coefficient would vary across repeated samples. Smaller means more precise.
  • t-statistic and p-value: test whether the true coefficient could be zero. A p-value below 0.05 is "significant at 5%" (two stars).
  • 95% confidence interval: the range of values compatible with the data.
  • R² and adjusted R²: the share of the variation in Y explained in this sample. Adjusted R² penalizes extra variables.
  • F-test: are all the slope coefficients jointly zero?
Standard errors, t-test, F-test
\hat V(\hat\beta) = \hat\sigma^2 (X^\top X)^{-1}, \quad \hat\sigma^2 = \frac{\text{SSR}}{n-k}, \qquad t_j = \frac{\hat\beta_j}{\operatorname{se}(\hat\beta_j)} \sim t_{n-k}
\bar R^2 = 1 - (1-R^2)\frac{n-1}{n-k}, \qquad F = \frac{(\text{SST}-\text{SSR})/(k-1)}{\text{SSR}/(n-k)} \sim F_{k-1,\,n-k}

n = observations, k = number of coefficients including the constant.

When the classical standard errors are wrong

The classical formula assumes the errors have the same spread everywhere (homoskedasticity). Wages, prices and incomes usually vary more at higher levels. Then the coefficients are still fine, but the classical standard errors, t-tests and p-values are not. Robust (HC1) standard errors remain valid. The Breusch-Pagan test checks for this problem; the Jarque-Bera test checks whether the residuals look normal, which matters for exact tests in small samples. Look at the residual plot: a funnel shape signals heteroskedasticity.

Robust (White / HC1) covariance
\hat V_{HC1}(\hat\beta) = \frac{n}{n-k}\,(X^\top X)^{-1}\Bigl(\sum_i \hat\varepsilon_i^2\, x_i x_i^\top\Bigr)(X^\top X)^{-1}

Reading the machine learning output

The model is estimated on the training rows only and then used to predict the test rows, which play the role of new data. RMSE is the typical size of a prediction error, in the units of Y; MAE is the average absolute error and is less sensitive to a few large misses. If the test error is much larger than the training error, the model has learned noise that does not repeat: it overfits. Test R² can even be negative: then the model predicts worse than simply using the average.

Prediction metrics on a sample of m observations
\text{RMSE} = \sqrt{\tfrac{1}{m}\textstyle\sum_i (y_i-\hat y_i)^2}, \qquad \text{MAE} = \tfrac{1}{m}\textstyle\sum_i |y_i-\hat y_i|, \qquad R^2_{\text{test}} = 1 - \frac{\sum_i (y_i-\hat y_i)^2}{\sum_i (y_i-\bar y_{\text{test}})^2}

More variables: better fit, not always better predictions

Adding an X variable can never lower the training R². But if the new variable is unrelated to Y, its coefficient only fits noise, and the test error usually gets worse. That is the simplest form of overfitting, and the reason adjusted R², AIC and BIC penalize extra parameters.

Deep dive

Gauss-Markov. Under linearity, random sampling, no perfect collinearity, E[\varepsilon\mid X]=0 and homoskedasticity, OLS is the best linear unbiased estimator. Heteroskedasticity does not bias \hat\beta but invalidates \hat\sigma^2(X^\top X)^{-1}; the sandwich estimator above is consistent under heteroskedasticity of unknown form (White, 1980). HC1 multiplies by n/(n-k) as a small-sample correction.

Breusch-Pagan (Koenker version). Regress \hat\varepsilon_i^2 on the X variables; LM = nR^2_{aux} \sim \chi^2_{k-1} under homoskedasticity. Jarque-Bera: JB = \tfrac{n}{6}\bigl(S^2 + \tfrac{(K-3)^2}{4}\bigr) \sim \chi^2_2, with S the skewness and K the kurtosis of the residuals.

Information criteria. With Gaussian log-likelihood \ell = -\tfrac{n}{2}\bigl(\ln 2\pi + \ln(\text{SSR}/n) + 1\bigr): \text{AIC} = -2\ell + 2k, \text{BIC} = -2\ell + k\ln n. Lower is better; BIC penalizes extra parameters more heavily.

Why in-sample fit overstates predictive accuracy. For OLS with homoskedastic errors, the expected training MSE is \sigma^2(n-k)/n, while the expected error on new data drawn at the same X values is about \sigma^2(n+k)/n. The gap grows with the number of parameters k relative to n: this is the optimism that a test set reveals.

From the simulation to real data

  • Use Load CSV / Excel in the Data panel to estimate a regression on your own file: choose Y and any number of numeric X columns.
  • Check the residual plot and the Breusch-Pagan test before trusting the classical standard errors; with cross-section economic data, robust standard errors are the safe default.
  • If your goal is forecasting, judge the model by its test error, not by R².
