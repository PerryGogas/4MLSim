What this module shows

To forecast next month, a recurrent network reads the past months one at a time and carries a memory from step to step. The LSTM (long short-term memory) controls that memory with three gates: the forget gate (keep or drop the old memory), the input gate (how much of the new month to write) and the output gate (how much of the memory to show).

The real test: does it forecast new months better than a simple autoregression or "no change"?

How to use it

  1. Press Reset, then Play: watch the forecasts fit the series and the loss fall.
  2. Pick a forecast and read the gates month by month, and the last step in numbers.
  3. Compare the test RMSE with the AR and no-change benchmarks; change the window and the units.

Recurrent networks

A feed-forward network sees all its inputs at once. A recurrent neural network (RNN) reads a sequence one step at a time and keeps a hidden state h that summarizes what it has seen so far: ht = f(new input, ht−1). The same weights are used at every step. Unrolled over a 12-month window, it is a 12-layer network.

Training it means backpropagation through time: the gradient passes back through all the steps. In a simple RNN it is multiplied at every step and tends to vanish (or explode), so the network cannot learn long memories.

The LSTM cell

The LSTM adds a cell state c, a memory line that passes from step to step with only small, controlled changes. Three gates, each a sigmoid between 0 (closed) and 1 (open), decide:

  • Forget gate f: how much of the old memory to keep (1 = keep all).
  • Input gate i: how much of the new candidate content (from this month's value) to write into memory.
  • Output gate o: how much of the memory to pass on as the hidden state h, which is what the forecast is made from.

Because the memory is updated by adding (not by repeated multiplication through a squashing function), gradients survive many steps.

Forecasting with an LSTM

  1. Standardize the series with the training months' mean and standard deviation.
  2. Cut it into windows: the past L months are the input, the next month is the target.
  3. Keep the time order: the first 80% of the windows are the training set, the last 20% the test set (no shuffling; see Time-Series Validation).
  4. Train with backpropagation through time (here with the Adam optimizer) and compare the test RMSE with simple benchmarks.

On short economic series an LSTM often does not beat a well-specified autoregression: it has many weights for few observations. Its strengths show with long series, many related series, and nonlinear patterns.

The LSTM equations
f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f), \quad i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i), \quad o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o)
\tilde c_t = \tanh(W_c x_t + U_c h_{t-1} + b_c), \qquad c_t = f_t \odot c_{t-1} + i_t \odot \tilde c_t, \qquad h_t = o_t \odot \tanh(c_t)
\hat y_{T+1} = v^\top h_T + c_0, \qquad \text{loss} = \frac{1}{n} \sum (\hat y - y)^2

These are the equations of PyTorch's and Keras' LSTM. The gradients in this module were checked against numerical derivatives.

Deep dive

Why the cell state helps. ∂ct/∂ct−1 = ft: when the forget gate is near 1, the gradient passes back almost unchanged. The forget-gate bias is often started at 1 (as here) so the cell remembers by default.

Variants. The GRU merges the forget and input gates; stacked LSTMs use several layers; sequence-to-sequence models forecast many months at once. Transformers (see the LLM module) replace recurrence with attention.

Evaluation. Compare out-of-sample with benchmarks, and test whether the gain is significant (Diebold-Mariano test; see the Data Snooping module for the risk of trying many models).

References: Hochreiter and Schmidhuber (1997), "Long short-term memory", Neural Computation; Gers, Schmidhuber and Cummins (2000), "Learning to forget"; Goodfellow, Bengio and Courville (2016), Deep Learning, ch. 10.
