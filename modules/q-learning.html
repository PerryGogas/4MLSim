What this module shows

In reinforcement learning nobody gives the right answers. An agent acts, receives rewards or penalties, and learns from experience which action is best in each situation (a policy).

Q-learning keeps a table Q(state, action): the total future reward it expects from taking that action there and acting well afterwards. After every move it nudges the table towards what it just experienced. Here the agent walks on a grid towards a goal, avoiding traps; every move costs a little.

Learning from rewards

Supervised learning learns from examples with the right answer. Reinforcement learning learns from consequences: the agent is in a state, chooses an action, gets a reward and moves to a new state. Its aim is the largest total reward over time, not the largest immediate one: a costly step now can lead to a big reward later.

  • The discount γ (between 0 and 1) says how much a reward one step later is worth today: γ = 0.9 makes a reward 10 steps away worth 0.910 ≈ 35% of its size. Economists know it as the discount factor.
  • The policy tells the agent what to do in each state: here, the arrows.

Q-learning

Q(s, a) estimates the total discounted reward of taking action a in state s and acting well afterwards. After each move from s to s′ with reward r, the estimate is moved towards the reward plus the discounted value of the best action in s′:

new Q = old Q + α × (r + γ × best Q in s′ − old Q)

The value of the goal spreads backwards, one step at a time, through the grid. The agent needs no map of the world: it learns from experience only (model-free).

Exploration versus exploitation

If the agent always takes the best-looking action, it may never discover a better route. With probability ε it takes a random action instead (ε-greedy). An optimistic start (all Q values high) also pushes it to try everything once. Too much exploration wastes moves and, on the cliff, makes the agent fall in often while learning.

The Bellman equation and the update
Q^*(s, a) = \mathbb{E}\bigl[r + \gamma \max_{a'} Q^*(s', a') \mid s, a\bigr]
Q(s, a) \leftarrow Q(s, a) + \alpha \bigl[r + \gamma \max_{a'} Q(s', a') - Q(s, a)\bigr]

Value iteration solves the Bellman equation directly when the rules of the world (the move probabilities) are known; it gives the optimal Q* shown at the bottom. Q-learning approaches Q* from experience alone.

Deep dive

Convergence. Q-learning converges to Q* if every state-action pair is tried infinitely often and the learning rate shrinks suitably (Watkins and Dayan, 1992). With a fixed α the estimates keep fluctuating around Q*.

Off-policy. The update uses the best action in s′, not the one the exploring agent will actually take. So Q-learning learns the optimal path along the cliff edge even while its random steps make it fall; SARSA, which uses the action actually taken, learns a safer path.

Economics. The Bellman equation is the same as in dynamic programming models of consumption, investment and search. Deep Q-networks replace the table with a neural network for huge state spaces.

References: Bellman (1957), Dynamic Programming; Watkins and Dayan (1992), "Q-learning", Machine Learning; Sutton and Barto (2018), Reinforcement Learning: An Introduction, ch. 6.
