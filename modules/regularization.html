What this module shows

We explain flat prices with 7 variables that matter (floor area, rooms, age, ...) and a few that do not (photos in the ad, day listed, ...). With many variables and few flats, OLS fits noise: its coefficients are too large and unstable, and it predicts new flats poorly.

Regularization adds a penalty λ on the size of the coefficients. λ = 0 is OLS. As λ grows:

  • Ridge shrinks all coefficients towards zero, but never exactly to zero.
  • Lasso shrinks them and sets some exactly to zero: it also drops variables.

How to use it

  1. Start at λ = 0 and read the OLS coefficients in the table, next to the true values.
  2. Move the λ slider to the right and watch the coefficients shrink, in the table and in the charts.
  3. The error chart shows the λ where the cross-validation error is lowest; press Best λ by CV to go there.
  4. Compare Ridge and Lasso: which one drops the useless variables?

Why penalize coefficients?

OLS is unbiased, but when there are many variables relative to the number of observations, or the variables are strongly correlated, its coefficients have a large variance: they swing from sample to sample and the model predicts new data poorly. Regularization deliberately accepts a little bias to remove a lot of variance (see the Bias-Variance module). It adds to the OLS objective a penalty that grows with the size of the coefficients, so a coefficient is allowed to be large only if it really improves the fit.

Penalized least squares (X standardized, intercept not penalized)
\hat\beta(\lambda) = \arg\min_{\beta}\; \frac{1}{2n}\sum_{i=1}^n \bigl(y_i - \beta_0 - x_i^\top\beta\bigr)^2 + \lambda\, P(\beta)
\text{Ridge: } P(\beta) = \tfrac12\textstyle\sum_j \beta_j^2 \qquad \text{Lasso: } P(\beta) = \textstyle\sum_j |\beta_j| \qquad \text{Elastic net: } P(\beta) = \alpha\sum_j|\beta_j| + \tfrac{1-\alpha}{2}\sum_j\beta_j^2

This is the scaling used by glmnet and scikit-learn's ElasticNet. With λ = 0 all three are OLS.

Ridge, lasso and elastic net

  • Ridge (Hoerl and Kennard, 1970) shrinks every coefficient proportionally. It was invented for multicollinearity: with correlated regressors it spreads the effect over them instead of letting their coefficients explode in opposite directions. It never sets a coefficient exactly to zero.
  • Lasso (Tibshirani, 1996) subtracts a fixed amount from each coefficient and stops at zero. Weak variables are dropped completely: the result is a sparse model that is easier to read. Among strongly correlated variables it tends to keep one and drop the others, somewhat arbitrarily.
  • Elastic net (Zou and Hastie, 2005) combines both: it selects variables like the lasso but keeps groups of correlated variables together like ridge.

Standardize first

The penalty treats all coefficients alike, but a coefficient's size depends on the units of its variable (euros or thousands of euros, metres or square metres). The variables are therefore standardized (mean 0, standard deviation 1) before the penalty is applied, using the training data only. The coefficient paths are shown in these standardized units: the effect of a one-standard-deviation change.

Choosing λ by cross-validation

λ = 0 is OLS; a very large λ sets every coefficient to zero and predicts the average. The best λ lies in between. It must be chosen without touching the test (hold-out) set, so it is chosen by cross-validation on the training set: the training set is split into 4 folds; the model is fitted on 3 folds and its error measured on the remaining one, the validation fold; this is repeated so that each fold is the validation fold once, and the 4 errors are averaged (see the Cross-Validation module). The 1-SE rule picks the largest λ (the simplest model) whose CV error is within one standard error of the lowest. The chosen model is then refitted on the whole training set and evaluated once on the test set.

Cross-validation error and the 1-SE rule
\text{CV}(\lambda) = \frac1K\sum_{k=1}^K \text{MSE}_k(\lambda), \qquad \lambda_{1SE} = \max\{\lambda : \text{CV}(\lambda) \le \text{CV}(\lambda_{\min}) + \text{SE}(\lambda_{\min})\}

A warning for economists

Penalized coefficients are biased towards zero and the lasso's choice of variables can change from sample to sample, so they should not be read as causal effects or tested with the usual t-tests. Regularization is a tool for prediction. When the goal is a causal effect with many controls, use methods built for it, such as post-double-selection (Belloni, Chernozhukov and Hansen, 2014) or double machine learning.

Deep dive

Closed forms with orthonormal regressors (X^\top X/n = I): ridge gives \hat\beta_j = \hat\beta_j^{OLS}/(1+\lambda), proportional shrinkage; the lasso gives the soft-thresholding rule \hat\beta_j = \operatorname{sign}(\hat\beta_j^{OLS})\,(|\hat\beta_j^{OLS}|-\lambda)_+, which sets small coefficients exactly to zero.

Computation. Ridge has the closed form \hat\beta = (X^\top X/n + \lambda I)^{-1}X^\top y/n, which exists even when there are more variables than observations. The lasso and elastic net have no closed form; 4MLSim uses cyclic coordinate descent with soft-thresholding and warm starts along a decreasing λ path (Friedman, Hastie and Tibshirani, 2010). The lasso is zero for every λ at or above \lambda_{\max} = \max_j |x_j^\top (y-\bar y)|/n.

Constraint form and geometry. Equivalently, minimize the squared errors subject to \sum_j \beta_j^2 \le t (ridge) or \sum_j|\beta_j|\le t (lasso). The elliptical contours of the squared errors first touch the lasso's diamond typically at a corner, where some coefficients are zero; they touch ridge's circle at a point where none is.

Bayesian reading. Ridge is the posterior mode under a normal prior on the coefficients; the lasso under a Laplace (double exponential) prior.

References: Hoerl and Kennard (1970), Technometrics 12(1); Tibshirani (1996), JRSS B 58(1); Zou and Hastie (2005), JRSS B 67(2); Friedman, Hastie and Tibshirani (2010), J. of Statistical Software 33(1); Belloni, Chernozhukov and Hansen (2014), J. of Economic Perspectives 28(2); James, Witten, Hastie and Tibshirani (2021), An Introduction to Statistical Learning, ch. 6.

From the simulation to real data

  • Typical uses in economics and finance: forecasting with many indicators (macro forecasting with large panels of series), credit scoring with many applicant characteristics, nowcasting, and selecting controls before estimating a causal effect.
  • Always standardize using the training set only, choose λ by cross-validation on the training set, and report the error on the test (hold-out) set once, at the end.
  • With time series, use walk-forward validation instead of random folds (see the Time-Series Validation module).
  • Software: glmnet (R), scikit-learn's Ridge, Lasso, ElasticNet and their CV versions (Python), lasso and elasticnet commands in Stata.
