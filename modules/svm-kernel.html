What this module shows

When the data look like two clouds, a straight separator is easy to find. But when one class sits on both sides of the other (a ring around a circle, or bad banks with too much and too little debt), no straight line can separate them.

The kernel trick: project the data into more dimensions, where a straight separator exists. With one input x, add (x − average)²: the bad banks at both ends rise high on the parabola and a straight line cuts them off. Back in the original data the separator is a curve, or two cutoffs.

How to use it

  1. Start with the lecture example: banks with one ratio, debt-to-equity. Compare the linear and the polynomial kernel.
  2. Look at the lifted picture: the separator there is a straight line.
  3. Switch to the circles, moons or XOR data and try the RBF kernel and its width γ.
  4. Compare all kernels in the table, chosen by cross-validation.

When a straight line is not enough

When the data are like two clouds, it is easy to find a separator. When one class lies on both sides of the other, perfect separation is impossible; the parameter C lets the SVM accept some errors, but even then the accuracy can be very low (the lecture's real cases, e.g. credit cards). How can we overcome this?

The kernel trick: more dimensions

We project the data from the data space with n dimensions to a feature space with n + i dimensions (i = 1, 2, 3, ...). In the feature space the data can be linearly separable, or the accuracy increases significantly. The separator found there is a straight line (a hyperplane); seen back in the data space it is a curve.

  • Polynomial kernel, 1 dimension (the lecture's bank example): debt-to-equity too high means risk; too low means the bank does not use its equity to earn a return. Bad banks sit at both ends. Add a second dimension, (x − average)² (the same as adding x²): the ends rise on the parabola, and a straight line separates them. Back on the x axis: two cutoffs.
  • Polynomial kernel, 2 dimensions: add x1², x2² and x1·x2; circles and ellipses become straight lines in the feature space.
  • RBF (radial basis function) kernel: measures how close two observations are; it corresponds to infinitely many dimensions. Its width γ sets how far the influence of one observation reaches: small γ, smooth boundaries; large γ, wiggly boundaries that can overfit.

Why "trick"?

The SVM only needs the dot products between observations. A kernel computes the dot product in the feature space directly from the original inputs, without ever building the new dimensions. So the SVM can work in a huge (even infinite) feature space at the cost of the original one.

Kernels used here (inputs standardized)
\text{linear: } K(x, z) = x^\top z, \qquad \text{polynomial: } K(x, z) = (\gamma\, x^\top z + 1)^d, \qquad \text{RBF: } K(x, z) = e^{-\gamma \lVert x - z \rVert^2}
\text{degree 2, one input: } (\gamma x z + 1)^2 = 1 + \bigl(\sqrt{2\gamma}\,x\bigr)\bigl(\sqrt{2\gamma}\,z\bigr) + (\gamma x^2)(\gamma z^2): \text{ the lift } x \mapsto (x, x^2)
f(x) = \sum_{i \in SV} \alpha_i\, y_i\, K(x_i, x) + b

For the polynomial kernel γ = 1 / (number of inputs); the constant 1 inside the bracket is scikit-learn's coef0 = 1.

Deep dive

Mercer's condition. A function is a valid kernel if every kernel matrix it produces is positive semi-definite; then it is a dot product in some feature space. The RBF kernel's feature space has infinitely many dimensions.

Choosing the kernel and its settings. C and γ interact: both large means a very flexible boundary. They are chosen together by cross-validation, usually on a grid (see the Hyperparameter Tuning module).

Support vector regression uses the same kernels to fit curves with a tolerance band around them.

References: Boser, Guyon and Vapnik (1992), "A training algorithm for optimal margin classifiers", COLT; Schölkopf and Smola (2002), Learning with Kernels; Hastie, Tibshirani and Friedman (2009), The Elements of Statistical Learning, §12.3.

From the simulation to real data

  • Try the linear kernel first; use RBF when the classes are separated by curves (fraud, credit risk with interactions, bank ratios that are bad at both extremes).
  • Standardize the inputs, then choose C and γ together by cross-validation on the training set.
  • Kernel SVMs become slow beyond tens of thousands of observations; tree ensembles are then often easier.
